# Hacker Game

Welcome to the Hacker Game! This is a simulation game where you play as a hacker trying to infiltrate various systems.

## Features

- **Realistic Terminal Interface**: Experience the thrill of hacking through a simulated terminal.
- **Multiple Levels**: Progress through increasingly difficult levels with unique challenges.
- **Skill Tree**: Upgrade your hacking skills and unlock new tools.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akhil-kukku/hacker_game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd hacker_game
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

Start the game by running:
```bash
npm start
```
